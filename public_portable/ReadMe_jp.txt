# README (日本語)

このクローンパッケージは、itch.io での配布を想定して作られています。

対応ブラウザでそのまま閲覧できます。

## ローカルで実行する方法

index.html をダブルクリックしても正常に動作しない場合は、以下の方法をお試しください。

### 方法1: ローカルWebサーバーを起動する

Python がインストールされている場合は、以下のコマンドでローカルWebサーバーを起動できます。

bash python3 -m http.server 

その後、ブラウザで以下のURLを開いてください。

txt http://localhost:8000/ 

### 方法2: Tetorica mDrop を利用する

Tetorica mDrop を使用して、このパッケージを閲覧することもできます。

1. Tetorica mDrop を起動する
2. このパッケージをドラッグ＆ドロップする
3. コンテンツを開いて閲覧する

Tetorica mDrop:

https://kyorohiro.itch.io/tetorica-mdrop

## なぜWebサーバーが必要なのですか？

最近のブラウザでは、file:// プロトコルで開かれたローカルファイルに対してセキュリティ上の制限があります。

このパッケージでは、HTTP経由でのアクセスが必要なブラウザ機能を利用しています。

そのため、ローカルWebサーバー経由でアクセスすることで正常に動作します。
